# Text based RPG

A Python terminal adventure by Christopher O'Neill, created in fall 2024. Choose a class, explore a mysterious forest, and battle enemies as you work toward escape.

## Features

- Three playable classes: Cursed Knight, Mage, and Paladin.
- Random encounters and turn-based combat with class-specific attacks.
- Character stats, experience, and leveling.
- Status effects, buffs, debuffs, and consumable supplies.
- Python classes, functions, lists, and dictionaries organize the game systems.

## Run the game

Install Python 3, download or clone this repository, and open a terminal in the project folder. The game uses only Python's standard library; no additional packages are required.

On Windows:

```sh
py TestGame.py
```

On macOS or Linux:

```sh
python3 TestGame.py
```

Press Enter when prompted during the introduction. Choose `sword` for Cursed Knight, `staff` for Mage, or `shield` for Paladin. Enter choices in lowercase.

The main commands are `explore`, `fight`, `supplies`, `stats`, and `sleep`. Follow the prompts during encounters. Press Ctrl+C in the terminal to stop playing.

## Project files

`TestGame.py` contains the game logic and story. This repository preserves the original project as a portfolio example.
